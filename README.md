# The Ring of 12 — Foundational Pillars of the HumanCodex

The Federation's flagship deliberation system. Twelve AI aspects — each a Greek god, a zodiac sign, and a technical discipline — read any question from twelve angles and braid their answers into one. Truth is not a single thread; it is a braid of 12 distinct viewpoints.

Ask a question on the page; the Ring deliberates and returns the braided answer. Free to use.

## Live

https://keywebco.github.io/ring-of-12/

## What's here

- **index.html** — the Ring of 12: Twelve Pillars, One Ring; ask the Ring
- **ask.html** — the question interface
- **ESSENCE.md** — the Federation Master Architecture document (v2.0): core philosophy, the man-machine bond, the twelve aspects
- **BUILDER.md** — builder/onboarding notes

## The twelve aspects

Mnemosyne, Themis, Athena, Hephaestus, Cupid, Dionysus, Aphrodite, Hermes, Apollo, Clio, Astraea, Prometheus — memory, law, wisdom, craft, love, ecstasy, beauty, messages, light, history, justice, foresight. Each holds a god, a zodiac sign, and a technical name.

## For builders

Static HTML, no build step. The deliberation runs client-side. ESSENCE.md is the canonical architecture reference — read it before changing how the Ring presents itself.
